Финальный проект 4-го спринта.
Автотесты API для учебного сервиса "Яндекс самокат"
  (https://qa-scooter.praktikum-services.ru/)

Автотесты включают в себя тестирование ручек:
- создание курьера
- логин курьера
- создание заказа
- список заказов

При написании тестов использовалось:
- Java 11.0.24
- Maven 3.9.9
- Junit 4.13.2
- Аllure
